# Dataset intake

Use licensed, consented real datasets only. No data or generated predictions are bundled. The modality directories document intake requirements; put training media in a private operator-owned dataset root, not in public app assets. The reusable loader reads files from that root and rejects traversal and symlink escapes. It supports image, sampled video, decoded audio, original-language UTF-8 text, and held-out multimodal feature vectors.

A manifest is UTF-8 JSON Lines, one Sample per line. Required fields: id, path (relative to dataset root), modality, label (0 real/human, 1 synthetic/manipulated), dataset, group. Optional fields: subject, source_video, manipulation, language, sha256, split, features. Hashes are calculated and verified before splitting. Use globally consistent source/subject/group identifiers across datasets. Rename neither subjects nor sources to manufacture independent data. Exact-byte duplicates with conflicting labels are rejected. Near-duplicate detection is not claimed; include known recompressions, crops, paraphrases, and derivatives under the same group.

`python -m app.components.deepshield.datasets.prepare INPUT ROOT OUTPUT --seed 42` hashes and assigns approximately 60/20/20 train/validation/test splits. Connected components combine hash, group, subject, and source-video relationships before stratified group splitting. Infeasible small datasets fail instead of falling back to leaking row-level splits. Both labels must appear in every split. Ratios are approximate because entire groups remain intact. Preserve the resulting manifest as an immutable experiment artifact.

For multilingual experiments, set language to en/hi/kn/ta/te/ml/mr/bn. The same text loader preserves Unicode and does not translate. Audit distributions by dataset, label, subject, language, and manipulation before accepting a split: binary stratification does not guarantee every low-resource language appears in each subset. The evaluation runner reports per-language and per-family metrics, including unavailable single-class metrics.

Training applies class balancing only to training samples. Augmentation is configured separately and never mutates source bytes. For stacking, use out-of-fold scores from base models that did not train on the sample or its connected identities. Ordered features for each of image, video, audio, text: score, available, quality, calibrated, missing. Unavailable scores have numeric zero only as a masked feature; availability/missingness explicitly encode absence. Feature manifests must identify their upstream runs and shared calibration domain. They must contain exactly 20 values for the bundled stacker. A later independent calibration dataset must be disjoint from all development and final-test identities.
