# Multilingual intake

Use the text loader and original Unicode documents with language tags en, hi, kn, ta, te, ml, mr, bn. Manual labels should come from competent language review, not detector guesses. Hindi/Marathi and mixed-script/code-switched content need particular care. Group translations and paraphrases of a source together. Audit each language/label combination before training; missing language coverage must remain explicit in checkpoint validation metadata.
