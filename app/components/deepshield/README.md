# DeepShield service and experiment tools

## Safety contract

All detections return `ok`, `degraded`, `unavailable`, or `invalid_input`, nullable score, explicit score semantics, provenance, quality, evidence, warnings, and an uncertain verdict unless the configured calibrated fusion policy permits a decision. No trained weights, observations, measured accuracy, or fake example predictions are shipped. Missing models are not negative detections. Text factuality is always `not_assessed`.

The public service is ephemeral: requests are not persisted and responses say `persisted: false`. Temporary media is deleted after decoding. Face crops are returned only in the response, not saved in public assets. The existing SQLAlchemy schema is unchanged. `DetectionService.record_bundle` creates compatible Analysis/ModalityResult/EvidenceRecord objects for a future authorized persistence owner; it performs no writes and never puts an uncalibrated score into `fake_probability`. It omits crops/excerpts from stored metadata and sets a 24-hour review policy. No retention scheduler, history, reporting UI, authorization scheme, or upload experience is claimed in this phase.

## Service use

The running Reflex backend mounts the FastAPI service at `/api`. Its endpoints are GET `/api/health` and POST `/api/detect/image`, `/api/detect/video`, `/api/detect/audio`, `/api/detect/text`, `/api/detect/multimodal`.

Media JSON: `data_base64` containing raw standard base64 bytes, optional `language` (default auto), optional `explain` (default false). Text JSON: `text`, optional `language`. Multimodal JSON has any nonempty combination of image/video/audio media objects and a text object. Never pass paths, model IDs, or Python imports from client requests. Schema errors return 422, body limits 413, and busy admission 503. A valid request whose detector is unavailable returns an explicit unavailable result rather than a made-up score. Media decoding—not filename extensions—determines validity. The body cap applies before JSON parsing; decoded media is capped at 32 MiB, images at 16 megapixels, duration at 120 seconds, sampled frames at 12, and audio windows at 40. Responses can include bounded thumbnail and feature arrays.

`create_api` can be mounted by any compatible ASGI service. `DetectionService.detect` and `multimodal` are reusable synchronous backend methods. In a future Reflex background event, read state under its lock, run these methods with `asyncio.to_thread` outside the lock, and acquire the lock only to update results. The service serializes inference to bound memory. Its model cache is process-local immutable inference state, not user state or persistence. Startup and health checks do not import torch/librosa/ONNX Runtime or download models. Health distinguishes process liveness from model readiness and reports lazy models as not loaded.

Do not publish forensic input endpoints as an unrestricted anonymous service. Put an application-appropriate authenticated, rate-limited boundary around them. Decoder libraries should remain patched. FFmpeg subprocesses have time and duration bounds; native image/video decoding still needs an isolated resource-limited worker for adversarial media. HTTP request cancellation does not terminate an already-running native inference call. Do not enable request-body logging. Server diagnostics must remain private; API errors do not echo file paths, text, exceptions, or credentials.

The supplied research gave 12-character commit prefixes, not full SHA values. These are immutable revision selectors, not floating main/latest. Online provisioning resolves the selector to a full commit SHA and records it; local/cache-only provenance retains the supplied selector plus the exact artifact SHA256. Do not fabricate a longer SHA. Verify model cards, license files, architecture, and the complete commit during artifact approval. The ONNX path avoids Transformers preprocessing-version ambiguity, checks input rank/dimensions/type, and validates output cardinality/finiteness. This does not constitute independent validation of exporter correctness. FP32 is chosen rather than INT8/Q4 because the latter have reported out-of-distribution divergence.

Downloads are opt-in (`DEEPSHIELD_DOWNLOADS=1`); the default is cache/local only. Network provisioning checks public/ungated status and artifact size and refuses artifacts over 300 MiB. Image FP32 fits this budget. Dhwani's XLS-R front end may exceed it: it will be unavailable unless an approved local artifact is provisioned on a suitably resourced worker. Do not interpret its public availability as a small-model guarantee. Local artifacts require a SHA256 integrity pin. Settings accepts image_local/audio_local and corresponding SHA256 fields; the trusted operator may supply them to `DetectionService(Settings(...))`. No alternate model is substituted silently. API clients cannot configure checkpoints. Missing libraries, missing files, unsupported graphs, private/gated repositories, download failure, and inference failure fail closed.

Video selects uniform anchors plus high-change candidate frames, records per-frame status/score/quality, face thumbnails where Haar detection succeeds, optional image occlusion grids, temporal dispersion, and top-ranked timestamps. Its median and q90 summarize frame-baseline evidence; they are not a trained temporal result. Audio is not implicitly analyzed from video. Image localization can miss non-frontal faces; no-face does not mean real. Occlusion is sensitivity to a masking operation, not ground-truth manipulation localization. Audio emits waveform samples, log-mel arrays, independent three-second scores, and highest-scoring windows. Plots describe the signal, not causal model attribution. Rankings are not validated suspiciousness thresholds.

Dhwani's stated language scope is English, Hindi, Tamil, Telugu, Malayalam. Audio language auto-detection is not claimed: unknown or unsupported language degrades the result. Text language identification supports English, Hindi, Kannada, Tamil, Telugu, Malayalam, Marathi, Bengali through langdetect with reproducible seeding; short, ambiguous, and code-switched input can remain undetermined. Unicode input is preserved and never translated before detection.

## Team checkpoint contract

A trusted installed factory specified as `module:factory` returns an object with `provenance: Provenance` and `predict(payload) -> Result`. Constructors should not load large weights; predict loads lazily. Return a fully validated contract, exact preprocessing/version/license, language coverage, checkpoint hash, and held-out calibration identity when calibrated. Never use client-controlled import specs, arbitrary pickle objects, remote custom code, or guessed class order.

Settings text_adapter, temporal_adapter, and fusion_adapter select trusted factories. A temporal adapter receives original media bytes plus the sampled frame Result and must return modality video; its output is separate from attached frame evidence. Fusion receives all four modalities' availability, missingness, quality, calibration, score, degraded status, and disagreement. Default fusion refuses raw score averaging; only compatible calibrated inputs can enter a reliability-gated evidence summary, and that summary still abstains because it is not a jointly calibrated probability. A fitted stacking adapter must declare its own calibration identity. Policy abstains with fewer than two calibrated reliable inputs, strong disagreement, or within the configured abstention interval. Correlated image/video evidence must not be marketed as independent corroboration.

`adapters.MultilingualCheckpoint` is a ready local Transformers text adapter. Its operator-owned JSON config is read from DEEPSHIELD_TEXT_CONFIG and requires local_directory, repository, full revision, license, weights_sha256, languages, validation_id, and optionally fake_label_index/max_tokens/min_characters. It accepts a reviewed single-file safetensors binary checkpoint under 300 MiB, uses no remote code/downloads, preserves original-language tokenization, and reports chunk character offsets. It refuses unsupported languages. No multilingual origin checkpoint is enabled by default; no billion-parameter model is downloaded. Chunk scores are not factuality judgments and their median is explicitly uncalibrated.

`stacking.CalibratedStacker` consumes the artifact produced by the calibration CLI, through DEEPSHIELD_STACKING_ARTIFACT. It uses 20 ordered features documented in datasets/README.md. Use its factory only after held-out missingness/domain evaluation. Zero for a missing score is a masked numeric feature, never a reported neutral probability.

## Reproducible training

The five CLI entrypoints are `app.components.deepshield.training.train_image`, train_video, train_audio, train_text, and train_multimodal. Run each with `python -m MODULE --config CONFIG`. `training/example_config.txt` is a JSON configuration template; replace its operator-owned dataset/checkpoint paths. It is not a functioning sample dataset.

The shared engine verifies manifests and group splits, seeds Python/NumPy/torch, uses AdamW, ReduceLROnPlateau, optional training-only inverse-frequency sampling, gradient clipping, early stopping on validation BCE, best model selection, latest optimizer/scheduler checkpoint, and structured epoch logs. It never trains on final-test rows. Training records hashes of the manifest and selected checkpoint. This sandbox is CPU-only: AMP is intentionally disabled, and no CUDA branch is initialized. A GPU extension must use AMP only on a genuinely supported worker; no GPU acceleration is claimed here.

Bundled transfer models: approved local ImageNet MobileNetV3-small backbone + binary head for image, MobileNet + trained GRU for video, log-mel MobileNet transfer baseline for audio, a local reviewed multilingual Transformers sequence classifier for text, and a logistic stacker for multimodal features. These are team training architectures, not implementations of the public Dhwani or CommunityForensics training recipes. Supply an installed factory returning (torch model, encoder, collator, provenance) to use another reviewed architecture. The model must emit one binary logit per example. No pretrained model downloads occur implicitly. Text uses a local checkpoint directory; image/video/audio use a local compatible MobileNet state dict. Frozen backbones and small batches are default. Long documents are truncated for the training baseline, so evaluate this limitation or supply a document-aware factory.

For calibration, run `python -m app.components.deepshield.evaluation.calibrate_stacker --config CONFIG --checkpoint BEST --calibration-manifest MANIFEST --calibration-root ROOT --output ARTIFACT`. The calibration corpus must have independently labeled multimodal features, both labels, and no connected identity overlap with any training, model-selection, or final-test sample. Platt scaling exports a plain validated numeric artifact, not executable pickle. Representative source provenance and out-of-fold feature construction remain the dataset curator's responsibility.

## Measured evaluation

The five matching evaluation modules accept --config, --checkpoint, --output, optional --external-manifest/--external-root, and --transforms. Supported image transforms: none/compression/resize/noise. Audio: none/noise/background/codec/compression. Video: none/codec/compression/resize/video_quality. A real licensed background recording must be supplied for background mixing; image background replacement requires a separate reviewed segmentation adapter and is rejected rather than simulated. Text/multimodal robustness uses separately curated variant manifests, not heuristic paraphrases. Unsupported transforms fail explicitly.

Reports contain accuracy, precision, recall, F1, macro F1, balanced accuracy, ROC-AUC, confusion matrix, FAR, FRR, and audio EER, with per-dataset/language/manipulation subsets and unseen-family reporting. Positive label means synthetic; FAR is synthetic accepted as real, FRR is real rejected as synthetic. EER is linearly interpolated on the empirical ROC. Single-class metrics are null where undefined. A 0.5 threshold is experimental, not a validated operating point; supply a held-out threshold identity after choosing policy outside the test set. Cross-dataset mode rejects development identity/content overlap and reused dataset identities. Transform results must be compared with the clean baseline on the same samples. No generalization or accuracy claim is made until real held-out results exist.

## Checks

Run `python -m unittest discover -s app/components/deepshield/tests`. Tests cover schema invariants, null failure scores, missingness-aware fusion, original-language text unavailability, persistence mapping without writes, group leakage, repeatable splitting, route registration, lazy health, invalid inputs, and metric formulas. Numeric values in unit tests are mathematical fixtures, not predictions or displayed product data. No model download is needed for these checks. Full ONNX checkpoint integration and end-to-end real-media training/evaluation require approved artifacts and datasets and must be run separately.
